# Reference Media

## Purpose

This note tracks the photo references that help anchor the `Midnight BIO-Log`
healing lane and the adjacent hardware lineage.

The goal is not to turn the repo into a photo dump. The goal is to preserve
which visual references exist, what they document, and how they should be used
inside a public-safe case-study build.

## Hardware Bench References

The clearest hardware references currently tied to this lane are the bench
captures showing:

- copper spiral / coil surfaces
- oscilloscope readout
- terahertz sphere array
- the shared visual environment that later maps to `FG200.67` and `ARC15`

These bench captures are useful because they show the hardware branch as
something physically built and tested rather than existing only as poster copy
or abstract concept language.

## Recovery-Side Photo References

There is also a recovery-side reference set associated with the `Midnight`
healing lane.

Most important for the repo build is the photo set that includes:

- `Midnight` present in frame
- `PulsarTek IR` support hardware in frame
- the healing lane shown as a lived intervention context rather than only a
  later writeup

That matters because it ties the `Midnight BIO-Log` to a physical support
branch in a way that is easy to understand and hard to flatten into generic
storytelling.

### Current Reference Set

The current recovery-side reference set being held alongside the repo build
includes image files such as:

- `IMG_3041.HEIC`
- `IMG_2986.HEIC`
- `IMG_9773.HEIC`
- `IMG_2876 2.HEIC`
- `IMG_2875.HEIC`

These are being treated as source references rather than automatically being
embedded all at once.

The preferred direction for public-safe use is:

- select a shot that clearly shows `Midnight` together with the `PulsarTek IR`
  support lane
- use that image as the single strongest recovery-side anchor if a photo is
  surfaced in the repo or related documentation
- keep the rest of the set as reference material unless there is a deliberate
  reason to publish more

## Public-Safe Handling

The current recommendation is:

- bench hardware imagery can be used more freely in public-facing repo and site
  surfaces
- recovery-side imagery involving `Midnight` should be selected intentionally
  and used only when the exact shot is clearly public-safe
- raw image archives do not need to all be committed for the repo to preserve
  their evidentiary role

## Why This Matters

The reference media keeps three things tied together:

1. the biological recovery chronology
2. the hardware-support lineage through `PulsarTek IR`, `FG200.67`, and `ARC15`
3. the wider Codex 67 / Renaissance Field Lite build culture of self-built,
   self-designed, and self-funded concept systems

That combination is part of why the `Midnight BIO-Log` belongs in its own repo
instead of remaining only as a loose set of chats and memories.
