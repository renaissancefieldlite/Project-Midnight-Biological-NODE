This document summarizes the difference between the institutional path as it was
understood by the operator and the path actually taken.

| Area | Institutional path described in source material | Path actually taken in Midnight BIO-Log |

## Public-Safe Summary

The public-safe claim is not that every interpretive explanation is proven.

It is that the observed recovery timeline substantially outperformed the
expected slow-path framing that surrounded the initial diagnosis.

The strongest bounded comparison in the source material is to a path the
operator understood as roughly `8–10` weeks caged with heavier medication.

## Practical Read

What this matrix supports:

- the intervention path diverged sharply from the initial recommendation
- the subject recovered more quickly than the operator expected after the
  Humane Society / vet path
- heavy intake sedation, a `3–4` day post-exam gabapentin taper, `PulsarTek`,
  full exit from the longer med path, and uncaged recovery were part of
  the reported intervention structure
- after the first bowel movement, the operator concluded that sedation was
  creating more strain than relief
- after gabapentin was removed, the operator reports that diarrhea subsided and
  panic / erratic behavior eased while pain became easier to read as a movement
  metric
- the archive repeatedly frames the recovery as roughly `4x` faster than the
  expected slow-path baseline

What this matrix does not prove:

- that a single mechanism fully explains the recovery
- that the wider Alpha Lumen / Codex framing is independently medically proven
- that the repo should be read as formal veterinary instruction
