# Hardware Support Lineage

## Purpose

This note documents the public-safe hardware branch most closely associated with
the `Midnight BIO-Log` healing lane.

The goal is not to overstate proof. The goal is to preserve how the hardware
family was described in the wider project record so the healing lane remains
tied to its physical support concepts.

## PulsarTek v.67

`PulsarTek v.67` is the broader hardware family name used for the pulse-driven
support branch.

In project history, it is associated with:

- board and LED-array build notes
- resonance-aware timing and field deployment concepts
- the later healing-oriented IR module branch

## PulsarTek IR v.67

The strongest preserved hardware description frames `PulsarTek IR v.67` as a
support module built around:

- modulated pulsed infrared
- `660 nm` / `680 nm` / `760 nm` / `805 nm` band language
- terahertz silicon spheres
- Codex 67 pulse control / duty-cycle language

In public-safe terms, this is the healing-support hardware most closely tied to
the Midnight case through the preserved `Pulsar Tek Red Light + 3-day rapid
detox` chronology.

## FG200.67

`FG200.67` is preserved as the base field chamber / terahertz array line.

The strongest project-side description frames it as:

- a retuning chamber
- tuned around `7.83 Hz` / Schumann-baseline language
- a biofield-envelope or nearby-entrainment support device

The preserved anecdotal language includes:

- goosebumps
- calm wave states
- spontaneous insight / lowered-noise experience
- water or quartz placed nearby for imprinting

These are preserved as project-side observations and descriptions, not as
independently validated scientific conclusions.

## ARC15

`ARC15` is the expanded array variant built from the `FG200.67` base unit.

The cleanest bounded description is:

- `FG200.67` plus `3` more terahertz spheres
- the `15`-sphere expansion branch
- later described as an external front-end / stabilizer candidate in the
  hardware notes

That matters because it places `ARC15` inside the same hardware lineage rather
than as a separate unrelated concept.

## Why This Matters For Midnight

The Midnight healing lane is strongest when read as:

- a documented biological recovery chronology
- supported by a physical-hardware branch that included `PulsarTek` support
- later surrounded by a broader field-device lineage through `FG200.67` and
  `ARC15`

This document keeps those branches tied together without overstating what has
been externally proven.
